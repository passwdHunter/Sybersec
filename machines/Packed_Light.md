## Кратко

Анализ сетевого дампа `.pcap` в рамках расследования аномальной активности на зараженном узле. Цепочка расследования: фильтрация C2-трафика по порту `8080` → обнаружение загрузки Python-кейлоггера → реверс-инжиниринг алгоритма шифрования (XOR) и C2-ключа → извлечение Base64-пейлоадов из HTTP-кук с помощью `tshark` → расшифровка данных и получение флага.

## 1. Разведка

### Сканирование портов

*Поскольку исследование проходило в формате сетевой форензики (dfir/pcap), сканирование живых портов не проводилось — анализ выполнялся на готовом дампе трафика.*

### Перечисление сервисов

На основе жалоб пользователя о регулярных обращениях к порту `8080` дамп был отфильтрован в Wireshark:

```text
tcp.port == 8080

```

```text
HTTP/1.0 200 OK (SimpleHTTP/0.6 Python/3.11.2)
GET / HTTP/1.1 (Host: byte-lotus-hotel.thm)
Cookie: hotel_sess_state=...

```

Анализ пакетов выявил следующую хронологию атаки:

1. **Загрузка малвари:** Зараженный компьютер обратился к серверу `SimpleHTTP/0.6 Python/3.11.2` по порту `8080` и скачал вредоносный Python-скрипт.
2. **C2-активность:** Скрипт ежесекундно инициализировал новое TCP-соединение и отправлял HTTP-запросы к C2-серверу (`C2_URL = "[http://byte-lotus-hotel.thm](http://byte-lotus-hotel.thm)"`).

## 2. Получение доступа

Исследование исходного кода скачанного Python-файла подтвердило наличие кейлоггера. Скрипт перехватывал нажатия клавиш библиотекой `pynput`, упаковывал их в HTTP-куку `hotel_sess_state` и отправлял на сервер.

Внутри кода обнаружена функция XOR-шифрования и составной ключ:

* **Часть 1:** `H0t3lSt@ff0Nly`
* **Часть 2:** `K3epS3cr3t!`
* **Итоговый ключ:** `H0t3lSt@ff0NlyK3epS3cr3t!`

Для изоляции пакетов с перехваченными данными использовался фильтр:

```text
http.cookie contains "hotel_sess_state=" && !(http.cookie == "hotel_sess_state=")

```

Извлечение всех значений кук в формате Base64 выполнено утилитой `tshark`:

```bash
tshark -r traffic.pcap -Y 'http.cookie contains "hotel_sess_state="' -T fields -e http.cookie

```

Прямой декодинг Base64 возвращал зашифрованный массив байт, что подтвердило использование XOR.

**Флаг пользователя:** `THM{V3r4_1s_w4tch1ng_0veR_y0u}` *(заменяет пользовательский флаг, так как в рамках форензик-таска флаг один)*

## 3. Повышение привилегий

*Раздел опущен, так как данное задание сосредоточено на анализе сетевого трафика и расшифровке данных, а не на эксплуатации эскалации привилегий в ОС.*

**Флаг root:** `THM{V3r4_1s_w4tch1ng_0veR_y0u}`

## Выводы

* **Уязвимости:** Компрометация узла с последующей загрузкой неподписанного Python-скрипта, отсутствие фильтрации исходящего HTTP-трафика на порту `8080`, использование стандартных библиотек (`pynput`) для шпионажа.
* **Как предотвратить:** Внедрить EDR/AV-решения для блокинга несанкционированного создания хуков ввода (keylogging), ограничить исходящий трафик с рабочих станций на нестандартные порты (Egress Filtering), использовать TLS для скрытия заголовков и кук.
* **Чему научился:** Быстрому парсингу и экстракции полей сетевых пакетов из `.pcap` с помощью `tshark`, анализу логики кастомных вредоносных Python-скриптов и реверсу XOR-шифрования на основе извлеченного C2-ключа.
